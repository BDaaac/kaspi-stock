# kaspi-stock

Раз в час берёт остатки из МойСклад и собирает прайс-лист для Kaspi.

- `mapping.csv` — артикул Kaspi → код МойСклад → сколько единиц МойСклад в одном товаре Kaspi.
- `kaspi_base.xml` — прайс из кабинета Kaspi: отсюда берутся цены, названия и склад.
- `build_feed.py` — остаток Kaspi = (остаток − резерв на «Основном складе») ÷ единиц в товаре, вниз.
- `docs/kaspi.xml` — готовый файл, его читает Kaspi.
